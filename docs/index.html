Comandos:
  _state     muestra estado global
  _reset     restaura la última configuración cargada
  _reload    recarga configuración guardada / URL
  _help      abre esta ayuda
  _stop      detiene reproducción
  _rec       inicia grabación; un segundo _rec detiene y descarga

Operadores:
  ! / !      centro_sonoro suma / resta
  + / -      dispersión suma / resta
  ) / (      suavidad_rítmica suma / resta
  } / {      lateralidad suma / resta
  ] / [      volumen suma / resta
  > / <      ritmo_ms_modulo suma / resta
  #          inversión ritmica
  ~          silencio global
  @          modelo de onda

Tipos de onda (@):
  0:square
  1:sine
  2:saw
  3:triangle
  4:wnoise
  5:bnoise
  6:rnoise

Comentarios:
  ;;token    ignora solo ese token
  ;;         ignora resto de linea

  Ctrl-P / Ctrl-N  historial
  Arriba / Abajo   historial
  Ctrl-A           inicio de linea
  Ctrl-E           fin de linea
  Ctrl-U           borrar hasta inicio
  Ctrl-K           borrar hasta fin
  Ctrl-Backspace   borrar palabra anterior
  Ctrl-C           stop
  Tab              autocompletar comandos

Tutorial

Cada palabra se sintetiza cuando aparece un espacio, tab o enter. Las letras ASCII son la materia sonora. Los números y signos modifican parametros del sonido.

Si una palabra no tiene letras, los modificadores cambian el estado global. Si una palabra tiene letras, los modificadores son locales. Varios modificadores locales son posicionales: afectan a las letras que aparecen despues de ellos.

Básico

hola
sonido

Modificadores globales

;; sube centro global
10!
alto

;; restaura centro
10¡
normal

;; sube dispersion global
3+
dispersa

;; restaura dispersión
3-

Dispersión local posicional

;; sin modificador local
sonidos

;; dispersion local 4+ aplicada a las letras siguientes
4+sonidos

Volumen local en cascada

;; palabra con volumen normal
normal

;; baja volumen local al principio y lo restaura después
[10bajo10]normal

Lateralidad e inversión

;; lateralidad por letra
a{b}c

;; inversion ritmica por tramos
al#ter#nos

Tempo global

;; tempo mas lento
5>
lento

;; restaurar tempo
5<
normal
